# Portfolio Navigation Design 🌐

A simple **multi-page personal portfolio website** built using **HTML5 and CSS3**. The project demonstrates website navigation, colorful gradient backgrounds, Flexbox layouts, rounded UI elements, and interactive hover animations.

## 📌 About the Project

This project is a basic personal portfolio website designed to practice the fundamentals of **HTML and CSS**.

The website is divided into multiple pages, allowing visitors to navigate between different sections such as Home, About, Projects, Achievements, and Contact.

The design uses colorful gradients, a rounded navigation bar, and hover effects to create a simple and visually appealing interface.

* 🌐 Multi-page portfolio website

## 📂 Project Structure

```text
portfolio-navigation-design/
│
├── index(3).html
├── About.html
├── project.html
├── Achivement.html
├── contact.html
└── README.md
```

### 📄 File Description

* **`index(3).html`** — Main/Home page of the portfolio.
* **`About.html`** — Contains information about the portfolio owner.
* **`project.html`** — Displays projects or project-related information.
* **`Achivement.html`** — Contains achievements and accomplishments.
* **`contact.html`** — Provides contact-related information.
* **`README.md`** — Project documentation.

> **Note:** For easier GitHub Pages deployment, it is recommended to rename `index(3).html` to `index.html`. If you rename any other HTML files, make sure to update the corresponding navigation links.

## 🚀 How to Run

### Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Rename `index(3).html` to `index.html`.
4. Open `index.html` in any modern web browser.
5. Use the navigation bar to explore the different pages.

### GitHub Pages

The project can also be hosted using **GitHub Pages**.

Make sure the main page is named:

```text
index.html
```

Then configure GitHub Pages to deploy the repository.
